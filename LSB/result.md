# Отчет по программе стеганографии в BMP-файлах

## Описание программы
Программа реализует метод стеганографии, скрывая текстовое сообщение внутри BMP-изображения.
Для этого каждый байт сообщения кодируется в младших битах значений цвета пикселей изображения.

Программа позволяет:
1. **Скрывать сообщение** в BMP-изображении.
2. **Извлекать скрытое сообщение** из BMP-изображения.

## Основные принципы работы
Программа работает с 24-битными BMP-файлами, где заголовок изображения занимает 54 байта.
Каждый байт скрытого сообщения кодируется в младших двух битах четырех последовательных байтов изображения.

### Кодирование сообщения
1. Читается BMP-файл и текстовый файл с сообщением.
2. В конец сообщения добавляется маркер окончания `0xFF`.
3. Сообщение кодируется побайтово:
   - Старшие 2 бита каждого байта записываются в младшие 2 бита первого байта пикселя.
   - Следующие 2 бита — во второй байт пикселя.
   - Следующие 2 бита — в третий байт пикселя.
   - Последние 2 бита — в четвертый байт пикселя.
4. Измененные байты сохраняются обратно в BMP-файл.

### Извлечение сообщения
1. Читается BMP-файл с внедренным сообщением.
2. Четыре байта пикселя декодируются в один байт сообщения.
3. Чтение продолжается до обнаружения маркера окончания `0xFF`.
4. Извлеченное сообщение сохраняется в текстовый файл.

## Описание функций

### `HideMessage(string bmpPath, string messagePath, string outputBmpPath)`
Функция скрывает сообщение в BMP-изображении.
- **Входные параметры:**
  - `bmpPath` — путь к исходному изображению BMP.
  - `messagePath` — путь к файлу с текстом для скрытия.
  - `outputBmpPath` — путь к выходному изображению с внедренным сообщением.
- **Алгоритм:**
  1. Читает содержимое BMP-файла и текстового файла с сообщением.
  2. Проверяет, достаточно ли места для сообщения.
  3. Кодирует сообщение в пиксели BMP.
  4. Записывает измененный BMP-файл на диск.

### `ExtractMessage(string bmpPath, string outputMessagePath)`
Функция извлекает скрытое сообщение из BMP-изображения.
- **Входные параметры:**
  - `bmpPath` — путь к BMP-файлу с скрытым сообщением.
  - `outputMessagePath` — путь к файлу, в который будет записано извлеченное сообщение.
- **Алгоритм:**
  1. Читает BMP-файл.
  2. Декодирует скрытое сообщение по 2 бита за раз.
  3. Записывает извлеченное сообщение в файл.

## Пользовательский интерфейс
Программа работает в консольном режиме и предлагает пользователю выбрать один из двух режимов:
1. **Скрытие сообщения** — пользователь вводит пути к изображениям и файлу с текстом.
2. **Извлечение сообщения** — пользователь вводит путь к BMP-файлу и файлу для сохранения текста.

Если ввод некорректен, программа выводит сообщение об ошибке.

## Возможные улучшения
- Поддержка других форматов изображений.
- Использование более сложных методов стеганографии.
- Шифрование сообщения перед внедрением.

## Заключение
Программа демонстрирует базовые принципы стеганографии, используя BMP-изображения для скрытия текстовых данных. Метод может быть применен для сокрытия информации, но легко обнаруживается при анализе изображения.
